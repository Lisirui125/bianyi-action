# bianyi-action
# 便医行动 MCP

便医行动是一个面向患者的就医路径规划与医保信息辅助 MCP 工具。用户提供症状、年龄、当前位置、医保类型和经济情况后，上层 Agent 可调用本 MCP 生成一份可执行的“就医任务单”，包括病情双轴分级、推荐科室、附近医疗机构、地图/打车入口、到院后流程、出发前准备清单和医保/报销政策提示。

本项目聚焦患者真实就医前最常见的问题：现在要不要急诊、应该挂什么科、去哪家医院更合适、进医院后先做什么、医保报销应该问哪些事项。项目不做疾病诊断、不替代医生、不承诺治疗效果、不直接开药。

## 项目简介

在日常就医场景中，患者往往无法判断“病情是否紧急”和“应该去哪家医院”。便医行动将就医决策拆成两个维度：

- 紧急程度：是否需要立即拨打 120、前往急诊，或可预约门诊。
- 严重程度：是否属于轻症、普通/中等、严重或危重风险。

MCP 根据症状危险信号、年龄、基础病、持续时间和经济情况进行规则化分流，并结合地图/位置数据生成行动建议：

- 脑梗、心梗、动脉出血、车祸外伤等急症：就近急救优先。
- 头疼、发热、流鼻涕、轻微咳嗽等常见轻症：就近基层/普通门诊优先。
- 癌症、肿瘤、尿毒症等非紧急但严重疾病：本地或全国专科中心优先。
- 经济困难场景：优先医保定点、本地可结算、可咨询医疗救助的路径。

## MCP 工具

本 MCP 提供 3 个工具。

### `get_intake_prompt`

新对话开始时调用，返回患者需要填写的信息提示。

必填信息：

- 症状/病情描述
- 年龄
- 当前位置，建议精确到小区、楼栋、学校、公司、商场或街道门牌

选填信息：

- 性别
- 持续时间
- 基础病
- 危险信号
- 医保类型
- 家庭收入或经济困难情况

### `search_nearest_hospitals`

根据症状分流结果和用户位置搜索附近医疗机构。

特点：

- 支持传入客户端定位 `lat/lng`。
- 用户没有经纬度时，可尝试用详细地址做免费地理编码。
- 支持高德地图 Web 服务，适合中国大陆正式效果。
- 未配置高德 Key 时，尝试 OpenStreetMap Overpass、免费地理编码和网页搜索兜底。
- 有用户坐标和医院坐标时，优先用免费 OSRM 计算驾车路线距离；失败时退回直线距离。
- 无法验证坐标或距离时，不伪造“最近医院”，会返回明确状态。

### `generate_care_plan`

生成完整就医任务单。上层 Agent 应优先调用此工具，并原样展示返回的 `care_plan_text`。

输出包含：

- 病情双轴分级
- 推荐路径策略
- 推荐科室
- 具体推荐地点
- 地图定位、导航、打车入口
- 备用选择
- 到院后行动步骤
- 出发前准备清单
- 见医生时说明要点
- 当地医保/报销政策卡
- 需要立即升级为急诊的情况
- 工具局限性声明

## 快速开始

### 1. 安装依赖

```bash
python -m pip install -r requirements.txt
```

### 2. 配置环境变量

复制 `.env.example`，按需配置环境变量。不要提交真实 API Key。

Windows PowerShell 示例：

```powershell
$env:MAP_PROVIDER="auto"
$env:AMAP_API_KEY="你的高德Web服务Key"
```

Linux/macOS 示例：

```bash
export MAP_PROVIDER=auto
export AMAP_API_KEY=你的高德Web服务Key
```

`AMAP_API_KEY` 可选，但推荐配置。没有高德 Key 时，MCP 会尝试免费数据源；免费数据源在中国大陆医疗 POI 覆盖不稳定，不适合作为生产级最近医院能力。

### 3. 启动 MCP

```bash
python mcp_server.py
```

这是 stdio MCP Server。启动后终端看起来会等待输入，这是正常现象，需要由 MCP Client 或 Agent 挂载调用。

## Agent 接入建议

系统提示建议：

```text
你是“便医行动”就医路径规划助手。

新对话开始时，先调用 bianyi-action MCP 的 get_intake_prompt，
把 intake_prompt 展示给用户。

当用户提供症状、年龄和位置后，调用 generate_care_plan。
如果客户端提供 lat/lng，一并传入；如果没有，只传用户详细地址。

输出时原样展示 generate_care_plan 返回的 care_plan_text。
不得自行编造医院、距离、医保比例、治疗效果或药物方案。
```

用户可以直接输入：

```text
我 68 岁，男，在河南省郑州市金水区正弘城附近，胸口压迫感 1 小时，出汗，喘不上气，有高血压，职工医保。
```

Agent 应提取字段并调用：

```json
{
  "symptoms": "胸口压迫感1小时，出汗，喘不上气",
  "age": "68",
  "location": "河南省郑州市金水区正弘城附近",
  "gender": "男",
  "duration": "1小时",
  "chronic_diseases": "高血压",
  "insurance_type": "职工医保",
  "income_context": "普通"
}
```

## 病情分级逻辑

当前 MVP 使用可解释规则做分流，不使用真实患者数据，不做医学诊断。

分级依据包括：

- 危险信号：胸痛、呼吸困难、意识异常、大量出血、疑似中风、严重过敏、高热、剧烈疼痛。
- 症状关键词：心梗、脑梗、卒中、车祸、动脉出血、癌、肿瘤、尿毒症、发热、头痛等。
- 年龄：儿童和老人风险提示更谨慎。
- 基础病：糖尿病、高血压、冠心病、肾病、免疫相关疾病等。
- 持续时间：无明确急救信号但持续时间较长时，建议更早门诊评估。
- 经济情况：经济困难时优先提示医保定点、本地结算和救助咨询。

分级输出：

- 紧急程度：极紧急、紧急、较急、非紧急。
- 严重程度：轻症、普通/中等、严重、危重风险。
- 路径策略：就近急救优先、就近基层/普通门诊优先、本地专科优先、全国/区域专科中心优先。

## 地图与距离策略

推荐生产接入：

```text
小程序/客户端获取 lat/lng
↓
MCP 调用高德/腾讯/百度地图地点搜索
↓
按病情策略筛选急诊、基层机构、普通医院或专科医院
↓
返回地图定位、导航、打车入口
```

当前 MVP 支持：

- 高德地图 Web 服务：配置 `AMAP_API_KEY` 后优先使用。
- OpenStreetMap Overpass：免费，但中国大陆医疗机构数据不完整。
- Nominatim：免费地址转坐标，不能保证楼栋/小区级覆盖。
- OSRM：免费路线距离，无实时路况。
- 网页搜索兜底：只能作为候选来源，不能稳定证明最近距离或实时接诊状态。

距离字段说明：

- `distance_type=driving_route_by_osrm`：免费 OSRM 驾车路线距离。
- `distance_type=straight_line`：直线距离，非实际路线。
- `distance_verified=false`：距离或坐标无法验证，不能当作最近医院依据。

## 本地测试

运行分级回归测试：

```bash
python triage_eval_cases.py
```

测试覆盖：

- 普通感冒样症状
- 皮疹瘙痒无呼吸困难
- 儿童高热精神差
- 糖尿病伤口一周红肿
- 慢性腰痛腿麻
- 疑似肺癌已做 CT
- 胸口压迫出汗喘不上气
- 疑似中风
- 车祸大量出血
- 严重过敏喉咙发紧

每次修改分级规则后，建议运行该脚本，检查分级是否符合预期。

## 合规声明

本工具仅用于就医路径和医保信息辅助，不构成医学诊断、治疗建议、医院治疗效果承诺或医保报销承诺。

本项目不使用真实患者数据。用户输入仅用于当前任务单生成。不要在代码、配置或示例数据中硬编码 API Key、身份证号、手机号、病历号、住院号等敏感信息。

真实医院地址、营业状态、号源、科室位置、楼层、收费和医保结算结果，请以医院、地图 App、医生和当地医保部门为准。出现胸痛、呼吸困难、意识异常、大量出血、疑似中风、严重过敏等危险信号时，应立即拨打 120 或前往最近急诊。
