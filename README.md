# 便医行动 MCP

## 1. 项目简介与医疗场景

- 一句话描述：便医行动是一个面向患者的就医路径规划与医保信息辅助 MCP，帮助用户根据症状、年龄、位置和医保类型生成完整的就医任务单。
- 解决的痛点：患者常常不知道是否需要急诊、该挂什么科、附近去哪家医疗机构、到院后如何挂号检查取药，以及本地医保门诊/急诊/大病规则如何理解。
- 目标受众：普通患者、家属、老年人和儿童监护人、外地医保用户，以及需要接入就医路径能力的医疗 Agent / 小程序开发者。

便医行动不做医学诊断、不替代医生、不承诺治疗效果、不直接开药、不承诺医保最终报销金额。工具输出用于就医路径和医保信息辅助，真实结论以医生、医院、地图 App 和当地医保部门为准。

## 2. 功能特性

- 病情双轴分级：同时输出紧急程度和严重程度，例如“极紧急/危重风险”“非紧急/轻症”“非紧急/严重”，避免只用单一维度判断。
- 就医地点推荐：基于用户详细位置调用高德地图，优先搜索附近医院、社区卫生服务中心、卫生院、急诊或专科机构，并返回导航、打车和地点链接。
- 到院任务单：输出具体 To Do List，包括先去哪里挂号、如何找导诊台、候诊、检查缴费、复诊、取药和向医生说明哪些信息。
- 医保政策数据库：内置 SQLite 医保政策库，支持居民医保普通门诊全国数据、部分城市职工/居民医保门诊、急诊、大病/慢特病规则，并展示起付线、报销比例、年度限额和来源。
- MCP 结构化返回：`generate_care_plan` 返回 `full_output`、`interactive_payload`、`action_checklist`、`reimbursement_summary` 等字段；外层 Agent 必须完整展示 `full_output`，不得摘要。

## 3. 魔搭社区运行 / 部署指南

- 魔搭展示链接：提交后补充 ModelScope MCP 公开链接
- MCP 提交入口：https://modelscope.cn/mcp/servers/create

### 本地运行步骤

```bash
pip install -r requirements.txt
python mcp_server.py
```

`mcp_server.py` 是 stdio MCP Server，启动后会等待 MCP Client / Agent / 魔搭平台调用。

### 环境变量

不要提交真实 Key。请在部署平台配置环境变量，仓库只提交 `.env.example`。

```bash
MAP_PROVIDER=auto
AMAP_API_KEY=你的高德Web服务Key
WEB_SEARCH_FALLBACK=true
POLICY_WEB_SEARCH=true
```

### MCP 工具

| 工具名 | 用途 |
| --- | --- |
| `get_intake_prompt` | 返回新对话需要收集的患者信息 |
| `resolve_location` | 将用户输入地址解析为坐标和行政区划 |
| `search_nearest_hospitals` | 单独搜索附近医疗机构 |
| `get_reimbursement_policy_card` | 单独查询医保/报销政策卡 |
| `generate_care_plan` | 生成完整便医行动任务单 |

```text

禁止直接联网搜索替代 MCP。
禁止自行编造医院、距离、医保政策或就医流程。

不得摘要、不得缩写、不得改写为自己的总结。

```

## 5. 局限性与未来规划

### 当前局限性

- 本工具不是诊断系统，只根据用户输入和规则生成就医路径建议。
- 地图结果依赖高德地图 Web 服务，医院营业状态、号源、楼层、科室位置和急诊能力仍需到院或地图 App 核验。
- 医保数据库用于就医前估算参考，最终报销金额取决于本人参保状态、费用目录、年度额度、医院医保系统和当地医保部门。
- 部分城市医保政策来自公开汇总表或用户提供数据，已标注来源和置信状态，但仍需要持续核验和更新。
- 工具不保存真实患者数据，示例均应使用模拟数据，不应输入身份证号、手机号、病历号等敏感隐私。

### 未来规划

- 扩充城市级职工医保、居民医保、少儿医保、大学生医保、异地医保政策库。
- 增加医保定点机构核验能力，区分“推荐机构是否支持当前医保类型直接结算”。
- 增加多轮追问机制，在缺少持续时间、危险信号、基础病、医保类型时主动补问。
- 接入更多医院官网或挂号平台公开信息，补充门诊时间、科室开放、急诊入口等信息。
- 建立政策数据定期复核流程，记录政策生效日期、来源链接、更新时间和置信状态。
